# 재능교육 1분 홍보 영상 (모션그래픽)

강조 포인트: **스스로학습** · **교육업 50년 전념** · 배경음악 **「자기의 일은 스스로 하자」**

## 구성 (60초)

| 시간 | 장면 | 내용 |
|---|---|---|
| 0–6s | 인트로 | 4색 도트 → 링 버스트 → `재능교육` 로고 타이포 |

| 17–33s | 스스로학습 | 타이틀 키네틱 → 카드 3장 (스스로 생각하고 / 스스로 풀고 / 스스로 자랍니다) |
| 33–45s | 노래 가사 | 계단 4칸 `자기의·일은·스스로·하자!` 위를 아이 캐릭터가 한 칸씩 올라감 |
| 45–53s | 50년 타임라인 | 1977 → 2027 (50주년) |
| 53–60s | 엔딩 | 재능교육 / 스스로학습 · 교육 50년 / ♪ 자기의 일은 스스로 하자 |

## 오디오 넣기

「자기의 일은 스스로 하자」 음원은 저작권 때문에 저장소에 들어 있지 않습니다. 사내 음원을 받아서 넣어 주세요.

1. `audio/song.mp3`로 저장합니다. `.wav`나 `.m4a`도 됩니다.
2. `node render.mjs`를 실행하면 음원이 자동으로 합쳐집니다. 60초로 자르고 시작 0.3초는 페이드인, 끝 2초는 페이드아웃합니다.
3. 노래 중간부터 쓰려면 `AUDIO_START=12 node render.mjs`처럼 시작 초를 지정합니다.

## 실행

```bash
npm install
pip install imageio-ffmpeg        # ffmpeg가 없을 때만
export FFMPEG=$(python3 -c "import imageio_ffmpeg as i; print(i.get_ffmpeg_exe())")
node render.mjs                   # out/jei_promo.mp4 (1920x1080, 30fps)
node render.mjs --preview         # 빠른 확인용 (15fps)
```

- 미리보기: `index.html`을 브라우저로 열면 재생 바가 나옵니다. `audio/song.mp3`가 있으면 노래도 같이 재생됩니다.
- 색상은 `index.html`의 `C` 팔레트에서, 문구와 타이밍은 `scene1`~`scene6` 함수에서 바꿀 수 있습니다.
